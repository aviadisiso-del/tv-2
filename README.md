# מסך בית זכוכית — GOtv+ GO700FR

מסך בית מותאם אישית (בסגנון הסרטונים) + סקריפטים לניקוי הסטרימר. הכול בעברית ו-RTL.

> **חשוב לדעת:** הקוד נכתב בסביבה בלי Android SDK ולכן **לא קומפל ולא נבדק על מכשיר**. עבר סקירה ידנית מלאה.
> ייתכנו תקלות קומפילציה קטנות בבנייה הראשונה — שלח לי את הודעת השגיאה ואני מתקן.

## מה יש בפנים
- מסך ראשי: **המשך צפייה** (Watch Next), שעון + מזג אוויר (Open-Meteo, מתרחב), נגן מוזיקה (Spotify וכו') עם גל התקדמות ותצוגה מורחבת, שורת אפליקציות זכוכית, סרגל צד (כל האפליקציות / תפריט מהיר / הגדרות).
- אנימציית פתיחה שמגדילה את הסמל/באנר של האפליקציה עצמה למסך מלא; כשהסמל או האפליקציה משתנים (עדכון/התקנה) הרשימה מתעדכנת אוטומטית.
- הגדרות: טפטים (כולל שמי פיקסל), ווידג'טים, עיר, הסתרת/סידור אפליקציות, אנימציות, פרופילי תצוגה, אקולייזר, לחצני שלט.
- **לחצן ⚙ בשלט (בתוך המסך שלנו):** לחיצה קצרה = ההגדרות שלנו, לחיצה ארוכה = הגדרות אנדרואיד המקוריות.
- **לחצן ה-TV שהקפת:** תפריט מהיר — תצוגה + סאונד (ניתן לשנות לאיזה לחצן הוא מקושר: הגדרות ← לחצני שלט ← "למד לחצן").
- **פרופילי תצוגה** (רגיל / קולנוע / ערב / לילה / חיסכון + מותאמים אישית) ו**אקולייזר** (שטוח / בס / גבוהים / דיבור / קולנוע / מוזיקה / לילה + מותאם אישית והוספת חדשים).

## חדש בגרסה זו
- **עמוד שני:** במסך הראשי לחץ ▼ (למטה) על שורת האפליקציות ← "המשך צפייה" + "המלצות" (המלצות אמיתיות מערוצי האפליקציות אם ניתנה הרשאה; אחרת "הכי בשימוש אצלך"). ▲ או חזרה — חוזרים.
- **נגן מוזיקה במסך מלא:** לחץ על שם השיר במסך הראשי.
- **ניקוי ופינוי מקום:** הגדרות ← "ניקוי ופינוי מקום": מקום פנוי, קיצור לניקוי מטמון, רשימת "מומלץ להשבית" והאפליקציות הגדולות. כל לחיצה פותחת את דף האפליקציה באנדרואיד (שם לוחצים "השבת"/"הסר"/"נקה מטמון"). אפליקציה לא יכולה להשבית אפליקציות מערכת בשקט — את זה עושה הסקריפט במחשב.
- **הרשאה להמלצות והמשך צפייה (דורש מחשב, פעם אחת):** `adb shell pm grant com.siso.glasslauncher com.android.providers.tv.permission.READ_EPG_DATA` (הסקריפט עושה את זה לבד).

## כיוון לחצנים בשלט (Button Mapper)
הגדרת הלחצנים המובנית הוסרה. במקומה האפליקציה חושפת פעולות שאפליקציות כיוון-לחצנים (כמו **Button Mapper**, נמצאת ב-Google Play) יכולות להפעיל:
1. התקן Button Mapper בטלוויזיה והפעל לה את שירות הנגישות לפי ההוראות שלה.
2. הוסף לחצן (למשל ⚙ או TV), בחר סוג לחיצה (רגילה / ארוכה / כפולה).
3. בחר "Launch app / Shortcut / Activity" ← מצא **"מסך בית זכוכית: ..."** ובחר אחת מארבע הפעולות: הגדרות, תפריט מהיר (תצוגה וסאונד), הגדרות אנדרואיד, מסך הבית.
4. אפליקציות שתומכות ב-Intent יכולות להשתמש גם בפעולות: `com.siso.glasslauncher.action.SETTINGS` / `QUICK` / `SYSTEM_SETTINGS` / `HOME`.

## שעון, נגן וטפטים
- שעון גדול ושקוף במרכז המסך (אפשר לכבות: הגדרות ← ווידג'טים ← שעון).
- הנגן במסך מלא עם רקע בגווני העטיפה.
- הטפטים נוצרים עכשיו ב-1920×1080 עם מניעת פסים; נוסף הטפט "דיונות" (ברירת מחדל).

## מגבלות כנות
- **תצוגה:** סטרימר לא יכול לשנות ניגודיות/חדות של הטלוויזיה עצמה (כמו מצבי התמונה של LG). הפרופילים מעמעמים ומחממים את התמונה שיוצאת מהסטרימר בלבד — זה דורש הפעלת שירות הנגישות. למצבי תמונה אמיתיים של הטלוויזיה השתמש בלחצן ההגדרות של השלט של ה-LG.
- **סאונד:** אקולייזר גלובלי תלוי בכך שה-ROM של הסטרימר מאפשר אפקט על session 0; אם אין שינוי בצליל — בדוק עם Spotify. כשהסאונד יוצא ב-HDMI/eARC לברקו או לטלוויזיה, ייתכן שהאקולייזר של הטלוויזיה/מקרן הקול טוב יותר.
- **המשך צפייה:** דורש הרשאת READ_EPG_DATA. אם ההענקה האוטומטית נכשלת השורה פשוט לא תוצג (שאר המסך עובד).

## 1. בניית ה-APK (אחת משתי דרכים)

### א. בענן עם GitHub (בלי להתקין כלום)
1. צור מאגר פרטי חדש ב-GitHub והעלה אליו את כל תוכן התיקייה הזו (כולל `.github`).
2. לשונית **Actions** ← "בניית APK" ← **Run workflow**.
3. בסיום (כ-5–10 דקות) הורד מ-**Artifacts** את `GlassLauncher-apk` וחלץ את `app-release.apk`.

### ב. ב-Android Studio
1. פתח את התיקייה ב-Android Studio (גרסה עדכנית), המתן לסנכרון.
2. תפריט **Build ← Generate Signed App Bundle / APK** או בטרמינל: `gradle assembleRelease`.
3. הקובץ: `app/build/outputs/apk/release/app-release.apk`.

חשוב לבנות **release** (לא debug) — Compose ב-debug איטי מאוד על סטרימר.

## 2. הכנת הסטרימר (ADB דרך הרשת)
1. בסטרימר: הגדרות ← מידע/על המכשיר ← לחץ 7 פעמים על **Build** (STTC.220803.001.9800) כדי להפעיל מצב מפתח.
2. הגדרות ← העדפות מכשיר ← אפשרויות מפתחים ← הפעל **ניפוי באגים ב-USB / ברשת**.
3. כתובת הסטרימר: 10.100.102.20 (אפשר לבדוק בהגדרות ← רשת). המחשב חייב להיות באותה רשת.
4. במחשב Windows: הורד **SDK Platform-Tools** מ-developer.android.com/tools/releases/platform-tools, חלץ ושים את התיקייה `platform-tools` לצד הסקריפטים (בתיקיית `tools`).

## 3. הרצת ההתקנה והניקוי (Windows)
בתיקיית `tools`, עם `app-release.apk` לצידה:
```
powershell -ExecutionPolicy Bypass -File .\install-tv.ps1 -Apk .\app-release.apk
```
(Linux/Mac: `./install-tv.sh 10.100.102.20 ./app-release.apk`)

הסקריפט:
1. מתחבר (אשר בטלוויזיה את חלון "לאפשר ניפוי באגים" וסמן "תמיד").
2. **מגבה**: רשימת חבילות, הגדרות, מסך הבית המקורי.
3. **שואל** מה להשבית (המלצות/פרסומות גוגל, שומר מסך, משוב, אפליקציות גוגל מיותרות, עוזר קולי, Live Channels, Chromecast, אפליקציות שהותקנו). השבתה **לא מוחקת** כלום.
4. משחרר מקום (ניקוי מטמון) ומציג מקום פנוי לפני/אחרי.
5. מתקין את ה-APK, מעניק הרשאות (גישת נגן מוזיקה, שירות לחצנים, הצגה מעל אפליקציות, המשך צפייה), וקובע אותו כמסך הבית.

אם המסך לא נקבע אוטומטית: לחץ HOME בשלט ← בחר "מסך בית זכוכית" ← **תמיד**.
אם שירות הלחצנים לא הופעל: הגדרות אנדרואיד ← נגישות ← "מסך בית זכוכית" ← הפעל.

## 4. בדיקה אחרי ההתקנה (עבור על הרשימה)
1. HOME — נפתח המסך החדש, האנימציות חלקות.
2. פתח אפליקציה — הסמל מתרחב למסך מלא; חזרה — מתכווץ חזרה.
3. ⚙ לחיצה קצרה — ההגדרות שלנו; ⚙ ארוכה — הגדרות אנדרואיד. נסה גם בתוך אפליקציה (נטפליקס/יוטיוב).
4. לחצן ה-TV — תפריט תצוגה/סאונד. אם לא קורה כלום: הגדרות ← לחצני שלט ← "תפריט מהיר" ← לחץ על הלחצן בשלט.
5. נגן Spotify — השיר מופיע במסך הבית (אחרי הענקת גישה).
6. אקולייזר: שים שיר, בחר "בס" ו"שטוח" ובדוק שיש הבדל שמיעתי.

## 5. החזרה אחורה
```
powershell -ExecutionPolicy Bypass -File .\restore-tv.ps1
```
מפעיל מחדש כל מה שהושבת ומחזיר את מסך הבית המקורי (`-Uninstall` מסיר גם את האפליקציה).

## פתרון בעיות
- **adb לא מתחבר:** ודא שניפוי באגים ברשת פעיל, IP נכון, ושהמחשב באותה רשת; נסה `adb kill-server`.
- **הלחצן בשלט לא עושה כלום:** הפעל את שירות הנגישות; ואם עדיין — "למד לחצן" בהגדרות ← לחצני שלט.
- **אין "המשך צפייה":** לא כל האפליקציות מדווחות; ובדוק שההרשאה ניתנה.
- **איטי:** ודא שזה APK של release ושהאנימציות פעילות רק אם צריך (הגדרות ← אנימציות).
